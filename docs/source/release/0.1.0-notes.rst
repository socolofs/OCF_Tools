=============================
OCF_Tools 0.1.0 Release Notes
=============================

..contents::

OCF_Tools 0.1.0 is the initial, beta release of the OCF_Tools package. It
contains the setup scripts, a working set of modules, and an outline of the
documentation. This release is intended to set up the structure for a future,
well-maintained distribution. This release is not intended to be complete.

Release highlight:

  - Installation is configured using Meson and the new pyproject.toml system
    and pip.
  - The package includes the last-used versions of ocf_tools.py, 
    culvert_tools.py, and storage_routing.py
  - The autodocumentation has been configured but not fleshed out with 
    examples and fully documented code.

New features
============

Pip installation functionality
------------------------------

This first release of OCF_Tools is distributed with the setup script
configured using Meson and pip. An environment.yml file defines all of the
required dependences. See the :doc:`Installation ../setup` instructions on how
to install this package.

Original OCF_Tools modules
--------------------------

Over the last three years, Dr. Socolofsky has created a set of Python modules
that perform various open-channel hydraulics calculations. This initial
release includes the latest version of each of these files prior to creation
of this Python package. These files are not yet integrated to tests to
inter-operability. This will be done in the coming releases.

Documentation
-------------

This release includes a complete set of documentation templates. The actual
contents of this documentation will be fleshed-out in coming releases. For
this release, the auto-doc feature that pull documentation from the source
code is the only feature that should be fully mature.
